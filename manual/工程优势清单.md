> ### 📏 本节所有数字怎么算（2026-10-28 补 · 审计要求）
>
> **原则**：数字会随代码演进变化，**给出算法比给出数值更重要**。
>
> | 数字 | 算法（可直接跑） |
> |:--|:--|
> | **部署体积** | `(Get-Item qcc_zh_seed.exe).Length / 1MB` |
> | **主源行数** | `([IO.File]::ReadAllLines("$PWD/srclib_jiayan/qcc_zh.jy",[Text.Encoding]::UTF8)).Count` |
> | **主源字节数** | `(Get-Item "$PWD/srclib_jiayan/qcc_zh.jy").Length` |
> | **interface 摘要大小** | `.\qcc_zh_seed.exe --interface srclib_jiayan/qcc_zh.jy > iface.txt; (Get-Item iface.txt).Length` |
> | **确定性（两次编译同哈希）** | `.\qcc_zh_seed.exe x.jy -o a.exe; .\qcc_zh_seed.exe x.jy -o b.exe; (Get-FileHash a.exe).Hash -eq (Get-FileHash b.exe).Hash` |
> | **feat_zh 用例数** | `(Get-ChildItem scripts/feat_zh_*.c).Count` |

> **⚠️ 路径坑（实测踩过）**：`[IO.File]::ReadAllLines("相对路径")` 的基准是 **.NET 进程工作目录**（可能是 `D:\.openclaw`），**不是** PowerShell 的 `Set-Location`。所以上面用 `$PWD` 拼绝对路径。`Get-Item`/`Get-ChildItem` 走 PowerShell 提供程序，相对路径正常。
>
> **⚠️ 口径提醒**：'`examples/multilang` 的「85 文件」**只算 `.c`**；目录下另有 2 个 CSV + 1 个 README，全部文件是 88 个。**引用时务必写明口径。**
>
> **⚠️ 2026-10-28 实测值**（供对照，**随时会过期**）：seed **15.43 MB** · 主源 **约 3.6 万行** · feat_zh **1,460 个** · multilang **85 个 .c / 50,692 行**。
>
> **⟹ 行数在本次审计期间就从 36,033 变到了 36,048（15 分钟 +15 行）** —— 这就是为什么本文只写「约 3.6 万行」。**要精确值请跑上面的命令，不要引用本段的数字。**

### 1. 部署体积：15.43 MB 单文件 vs rustc 1,292 MB

```
甲言 qcc_zh_seed.exe        14.54 MB   ← 单文件，零依赖，clone 即可用
gcc（bin 目录）             115 MB     ← 还需要头文件 / lib / cc1 / as
rustc 工具链                1,292 MB   ← 本机实测（含 lib/std）
```

**为什么重要**：一个乡下学校、一台没有管理员权限的机器、一个离线环境 —— **拷一个 14.5 MB 的文件就能编程序**。
不需要装工具链、不需要配 PATH、不需要 `apt install build-essential`。

**代价**（如实说）：甲言只出 Windows x86-64 PE；跨平台能力远不如 gcc/rustc。

> 复算：`(Get-Item qcc_zh_seed.exe).Length/1MB`

---

### 2. AI 读代码成本：`--interface` 把 2.61 MB 压到 174 KB（省 93.3%）

| 项 | 值 |
|:--|--:|
| 源码 `qcc_zh.jy` | **2,614,060 字符**（约 174 万–261 万 token，**任何 LLM 都读不完**） |
| `--interface` 导出 JSON | **174,784 字符** |
| **压缩比** | **15 倍 · 省 93.3%** |
| 导出内容 | **1,009 个函数签名** + **85 个结构体**（含字段偏移与大小）+ 46 typedef + 126 枚举 |
| 耗时 | 109 秒（解析期导出，不产码） |

```powershell
.\qcc_zh_seed.exe --interface srclib_jiayan\qcc_zh.jy > iface.json
```

**为什么重要**：AI 改这个编译器时，读 174 KB 就知道**所有函数的签名 + 所有结构体的内存布局**，
不用通读 2.6 MB 源码、也不会因为"读不完"而瞎猜。

**这是主流编译器没有的**：gcc 有 `-fdump-*` 各种 dump，但没有「一键导出可读 API 表面 + 结构体布局」的稳定接口。

> 相关的另外两个接口：`-graph`（调用关系图，需完整编译 ≈11 分钟）、`--refs`（谁引用了 X，解析期 ≈104 秒）。
> ⚠️ 别用 `-graph` 跑 34k 行主源 —— 要完整编译，实测 3 分钟仍不结束。

---

### 3. 确定性构建：两次编译，SHA256 一字不差

```
编译 #1  py1.c → a1.exe   SHA256 = 576FE2C9CC402733...
编译 #2  py1.c → a2.exe   SHA256 = 576FE2C9CC402733...
⟹ 完全一致
```

**为什么重要**：这叫 **reproducible build（可重现构建）**。
意味着「产物里没有任何时间戳、路径、随机数、ASLR 泄漏」——
**任何人拿同一份源码编出的东西，和你手里的东西逐字节相同**。

这是安全审计（供应链）、发布验证、以及「自举收敛」能成立的前提。
很多真实项目做不到这一点（Debian 花了十几年才让大部分包可重现）。

> 复算：编两次，`Get-FileHash` 比对。

---

### 4. 产物自证：`--selfcheck` 是 fail-closed 的

编译器可以**自己验证自己的输出**：

```powershell
# 用正确哈希（应通过）
.\qcc_zh_seed.exe py1.c -o c1.exe --selfcheck 576fe2c9...7eead
→ [SELFCHECK] OK: 576fe2c9...7eead      rc=0

# 用错误哈希（应拒绝）
.\qcc_zh_seed.exe py1.c -o c2.exe --selfcheck 00000000...0000
→ [SELFCHECK] FAIL: 576fe2c9...7eead != 0000...0000
   (不动点对账失败, 哈希审判 fail-已闭)   rc=1
```

**`fail-closed`（失败即关闭）** 是关键：哈希不符就**不产出、返回 rc=1**，而不是"警告一下继续"。
中文别名 `--自检` 与 `--selfcheck` **完全等价**（实测同一行为）。

**为什么重要**：这让「这个编译器有没有被投毒」变成一个**可自动化的判断**，不需要人读代码。

---

### 5. 信任根可审计：约 3.6 万行 vs gcc 约 400 万行

| 编译器 | 规模 | 一个人能读完吗 |
|:--|--:|:--|
| **甲言 `qcc_zh.jy`** | **约 3.6 万行** | 分段可以（配 `--interface` 导航，见 `manual/源码导航.md`） |
| gcc 核心 | 约 400 万行 | 不能 |
| clang/LLVM | 数百万行 | 不能 |

**为什么重要**：编译器是**信任根** —— 你所有程序的正确性都依赖它。
一个 约 3.6 万行的编译器，理论上**可以被一个安全团队逐行审计**；一个 400 万行的不行。

甲言还额外做了「减法设计」：**零外部依赖、不调 LLVM、单文件**——
意味着审计面就是这 34k 行本身，没有"底下还藏着别的东西"。

> 注意：34k 行对个人来说仍然巨大，且 5 个巨型函数占了 46%（详见 `manual/源码导航.md`）。
> **这条优势是「相对」的，不是「随便就能读完」。**

## 三、这些优势的代价（必须一起说）

| 换来了 | 代价 |
|:--|:--|
| 14.5 MB 单文件 | **只出 Windows x86-64**，没有 Linux/macOS 后端 |
| 极简信任根 | **生态为零**：没有包管理器生态、没有第三方库（只有自带的 jylib） |
| AI 接口齐全 | 大文件导出慢（`-graph` 要完整编译 ≈11 分钟） |
| fail-closed 自证 | 需要用户自己保存哈希；哈希一变就得更新 |
| 确定性构建 | 编译慢（完整自举 ≈830 s（8 核）/ 1,528 s（低配）），因为不做增量/并行 |

---

## 四、一句话总结

> **甲言的工程优势可以归成一句话：把一个编译器压缩到「一个人能信任、一台机器能装下、一个 AI 能读懂」的尺寸。**

14.5 MB / 约 3.6 万行 / 174 KB 接口摘要 / 两次编译 SHA 一致 / 哈希不符就拒绝 ——
这五条指向同一个方向：**可验证性**。而可验证性，恰恰是编译器这类软件最该有、也最常缺的东西。
