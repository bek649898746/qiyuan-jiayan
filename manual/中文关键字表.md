## 一、一句话结论：中文覆盖「语法骨架」，运算符沿用 C

| 类别 | 词元类型数 | 中文形态 |
|:--|--:|:--|
| **有中文关键字**（语句 / 类型 / 修饰） | **18** | ✅ 有 —— 中文原生 + 英文 C 兼容别名 |
| **纯符号**（运算符 / 标点 / 字面量） | **54** | ❌ 无 —— 与 C 完全一致 |
| 合计 | 72 | — |

> **精确计数（2026-10-18 逐条实测校准）**：中文关键字共 **38 个** =
> **15 个语句关键字**（`若`/`否`/`否则`/`循环`/`做`/`遍`/`择`/`例`/`缺`/`断`/`续`/`继续`/`返`/`返回`/`跳`）
> \+ **23 个类型与修饰关键字**（`整`/`字`/`字节`/`短`/`长`/`长整`/`单`/`双`/`空`/`无`/`无整`/`有符号`/`枚`/`枚举`/`构`/`类`/`结构体`/`联`/`联合`/`常`/`静`/`易失`/`大小`）。
> 上表「18」是**词元类型数**（一个类型可有多个中文别名），「54」是纯符号数，二者与 38 个**词**不是同一口径。
> ⚠️ 旧版本文档曾出现 39 / 42 两个数，已于 2026-10-18 统一订正为 **38**（仓内全库已对齐）。

⟹ 甲言**不是**「把 C 全部翻译成中文」，而是：

> **关键字中文化 + 符号层保持 C**（`+ - * / = < > & | ^ ~ ! ? : ; , . -> [ ] { } ( )` 与 C 完全一致）

**这正是它能兼容 C 的边界**：符号层零差异，语义层增加中文原生特性。
所以你能**中英混写**：`整` 与 `int`、`输出` 与 `printf` 是同一件事。

## 四、⚠️ 血泪坑：中文关键字**不能**用作变量名

源码 `语句关键字表[]` 的注释里记着实测事故（2026-10-05）：

```c
整 跳 = 0;              /* ← 跳 是关键字！ */
循环 (跳 < 5) { 跳++; }
```

**后果**：编译 **`rc=0` 零报错**，运行期直接 **`0xC0000005` 崩溃**。
因为 `跳` 被词法器当成了 `>` 运算符，整个声明被**静默丢弃**。

同类：`整 while = 5;` → 编译通过，**读出来是 0**（静默错值）。

> **规则**：关键字（上表所有词）**一律不能当变量名 / 函数名**。
> 命名时若拿不准，先查本表。这类错误**编译期不报**，只在运行期发作。

## 五、完整可跑示例

新建 `示例.jy`：

```c
/* 甲言示例：中文关键字 + 中文标识符 */
整 计算阶乘(整 甲) {
    若 (甲 <= 1) {
        返 1;
    }
    返 甲 * 计算阶乘(甲 - 1);
}

整 main() {
    整 和 = 0;
    遍 (整 序号 = 1; 序号 <= 5; 序号++) {
        和 = 和 + 计算阶乘(序号);
    }
    输出("阶乘之和 = %d\n", 和);

    若 (和 > 100) {
        输出("超过 100\n");
    } 否则 {
        输出("未超过 100\n");
    }
    返 0;
}
```

编译运行：

```powershell
gcc -O2 -Wall -Werror srclib/qcc_x86.c -o qcc_x86.exe
.\qcc_x86.exe 示例.jy -o 示例.exe
.\示例.exe
```

预期输出：

```text
阶乘之和 = 153
超过 100
```

> 同文件也可完全用英文写（`int` / `if` / `for` / `printf` / `return`），效果一致 —— **中英可混写**。

## 五之二、这些不是关键字，但是语言特性（2026-10-29 补）

> 由来（施工单 ORD-31）：`判别`/`依据`/`解构`/`通道`/`择收`/`线程` 都是**真语法**，
> 但本页只列关键字 ⟹ 新人按「表里查不到 = 不存在」推断，写出来的代码连续失败 4 次。
> 本节只写**能编译通过的写法**，每条都在 `tests/qcc/` 或 `examples/` 里有对应正例。

### 1. `判别`（可和 C 的 tagged union 互操作）

载荷语法是 **`类型 字段名`**（不是 `(类型)`）；缺字段名会报 `[ERR] 判别 载荷 缺字段名 (#97)`。

```c
判别 结局 于 { 成(整 值), 败(整 码), 空无() };

结局 果;
果.tag = 结局_成;   /* tag 常量 = <判别类型名>_<变体名>，由编译器生成 */
果.值 = 42;         /* 载荷按声明时的字段名访问 */
```

⚠️ 两种形态并存：**类型化载荷**（上面这种，推荐）与**旧式 `tag/p0/p1`**（编译器内部与部分老代码）。
新代码一律用类型化载荷；需要与 C 侧 union 互操作时看 `tests/qcc/regress_adt_typed.c`。

### 2. `依据`（穷尽分派）—— 是**语句**，不是表达式

```c
整 分支计 = 0;
依据 分支计, 果.tag 穷尽 结局 对照 结局_成: 1, 结局_败: 2, 结局_空无: 3;   /* 每个臂的值赋给第一个参数 */
```

臂里可以直接**绑定载荷字段名**（不用手写 `果.值`）：

```c
依据 area, c.tag 穷尽 Shape 对照 圆(半径): 3.0*半径*半径, 方(宽,高): 宽*高;
依据 n,     d.tag 穷尽 Shape 对照 Shape_圆: 1, Shape_方: 2, Shape_点: 3;   /* tag 常量写法 */
```

漏变体 ⟹ `A6016`，**不生成产物**。写成表达式（`整 x = 依据 …;`）会报 `A1004 缺少分号` —— 那不是语法错，是位置错。

### 3. `解构` —— 一次拿到「值 + tag」（用于三态错误联合）

语法是 `解构(值, tag) = <返回 错误 T 的调用>;`，**不是** `为 { … }`。tag：`0`=有值 / `1`=错 N / `2`=空。

```c
#包含 <stdio.h>
#包含 <string.h>
函数 错误 整 求长(常 字 *串) { 若 (串 == 0) 错 2; 若 (串[0] == 0) 返 空; 返 (整)strlen(串); }
函数 整 主(空) {
    整 v = -1, t = -1;
    解构(v, t) = 求长("甲言");
    格式化 "D2 v=%d t=%d\n", v, t;
    返 0;
}
```

### 4. `通道`（有界环形缓冲）

```c
通道 q, 4;          /* 声明：名字, 容量 */
送 q, 10;           /* 送：非阻塞；满时当前实现是「丢弃」——见文末已知限制 */
收 q, v;            /* 收：非阻塞；空时给 0 */
就绪(q)             /* 就绪判定：缓冲里有元素 */
通道已关闭(q)       /* 关闭标查询（配合 `关闭通道 q;`） */
```

### 5. `择收`（多路复用 + 缺省）

```c
择收(就绪(s1), 就绪(s2)) {
    例 0: 收 s1, x;
    例 1: 收 s2, y;
    缺:   缺省++;
}
```

编译期展开成 `若(就绪0) 例0体 否则 若(就绪1) 例1体 否则 缺省体`。
⚠️ 当前实现按**固定顺序**取第一个就绪分支（`例 1` 会饿死），见文末已知限制。

### 6. `线程` 与 `结构化并发`（编译器内建，**不需要自己写运行时**）

```c
线程 t 跑 干活, 10;        /* 起线程：函数 + 一个整参数 */
结构化并发 {
    线程 t1 跑 干活, 10;
    线程 t2 跑 干活, 20;
}                           /* 块退出自动 join 全部子线程 */
```

⚠️ **不要再自己写 `thread_create` 之类的同步空壳** —— 那会把「并发」示例变成串行（`examples/concurrency.jy` 曾有此坑，2026-10-29 已删）。

### 7. 两个常用但不是「关键字」的词

| 词 | 含义 | 说明 |
|:--|:--|:--|
| `函数` | 函数定义前缀 | 例 `函数 整 主(空) { … }`。**仅中文自举编译器 `qcc_zh_seed.exe` 支持**；C 宿主编译器不认，会报 `[ERR] 未找到 main 入口` |
| `主` | ≡ `main` | 入口函数名可用 `主` 或 `main` |

### 8. 已知限制（截至 2026-10-29，均已在台账留复现）

- `送` 在通道满时**静默丢弃**（rc=0、无告警）—— 需要「失败可见」或真阻塞，见台账 `ORD-20261027-29` 裁定。
- `择收` 按**源码顺序**依次判条件，命中第一个就执行；都未就绪则走 `缺:`。**非随机**（不是 Go 的随机 select）——但**两路都能命中**，不存在「只认第一个、后面的饿死」（2026-10-28 实测：`送 q2` 时正确走 `例 1`）。
- `可变借用` 是**独占冻结**（期间连通过指针写都被拦），与「Rust 的 `&mut`」不同名不同义 —— 对外表述应写「Rust 风格的部分静态检查」。
