## 〇、先读这一段：7 个「照直觉写会错」的坑

这 7 处语法，源码注释的示意和真实语法**不一致**。每个都让实测者踩过 2-3 次：

| 特性 | 直觉写法（错） | 真实语法 |
|:--|:--|:--|
| 宏 | `声明宏 平方(x) {...}` | **`#定义词 平方(x) ((x)*(x))`** |
| 通道发送 | `整 a = 送 q;` | **`送 q, a;`**（双参数，不是返回值） |
| 通道接收 | `整 a = 收 q;` | **`收 q, a;`** |
| 异常 | `捕获 { 抛出 42; }` | **`试 { 抛出 42; } 捕获 { ... }`**（跳转靠 `试`） |
| 实现接口 | `实现 T 于 S { 方法(空){...} }` | **`实现 T 于 S { 方法 = 函数名; };`** |
| 惰性 | `惰性 整 值 = 100;` | **`惰性 名, 函数, 参数;`**（三参数） |
| 导入 | `导入 模块名;` | **`导入 "文件";`**（独占一行，脱糖为 `#包含`） |

## 一、泛型

> **专题详述见 `manual/泛型单态化.md`** —— 那页有符号级验证（`objdump -t` 看 `恒等_整`/`恒等_双`）、`实例` 缺失时的完整报错、以及单态化的代码膨胀代价。本节只给速查。

### ⚠️ 先分清：甲言有**两套**泛型语法，语义完全不同

| | **真单态化**（推荐） | **旧宏语法** |
|:--|:--|:--|
| 定义 | `泛型函数 名(T) = 函数 T 名(T x) { ... }` | `泛型 名(x) = 体` |
| 实例 | `实例 名(整);` | 无需实例 |
| 调用 | `名[整](5)` | `名(5)` |
| 实现 | **词法分析前做源码级展开**，生成真实函数符号 | **文本级模板替换**（等价 C `#define`） |
| **实参求值** | **一次** | **可能多次**（C 宏陷阱） |
| 类型检查 | 有 | 无 |

**实参求值的实测证据**（用 `变++` 区分，这是唯一能看出差别的写法）：

```c
/* A. 真单态化 */
泛型函数 平方(T) = 函数 T 平方(T x) { 返 x * x; }
实例 平方(整);
整 变 = 0;
整 r = 平方[整](变++);        /* 实测：r=0 变=1 —— 只求值一次 ✅ */

/* B. 旧宏语法 */
泛型 平方(x) = ((x) * (x));
整 变 = 0;
整 r = 平方(变++);            /* 实测：r=0 变=2 —— 求值两次 ⚠️ */
```

**⟹ 新代码一律用「真单态化」形态。**

旧宏语法是**零依赖孤儿**：主源 `srclib_jiayan/qcc_zh.jy` 0 处、全部 `.jy` 源码 0 处，仅 14 个测试锚还在用。收敛方案见 `_施工单_S1_泛型双语法收敛.md`（2026-10-20 启元出）。

### 1.1 泛型函数 + 实例化（真单态化）
```c
泛型函数 恒等(T) = 函数 T 恒等(T x) { 返 x; }
实例 恒等(整);
实例 恒等(双);

函数 整 主(空) {
    整 a = 恒等[整](5);
    双 b = 恒等[双](2.5);
    空 *p1 = (空*)&恒等_整;
    空 *p2 = (空*)&恒等_双;
    格式化 "MONO %d %.1f %d\n", a, b, (p1 != p2);
    返 0;
}
```

**实测输出**：`MONO 5 2.5 1`

**真单态化的硬证据**：`p1 != p2` 为 `1` —— 生成的是两个**真实函数符号** `恒等_整` / `恒等_双`。文本宏替换不可能产生函数符号。

**官方用例**：`feat_zh_generic_mono_ok.c`

### 1.2 泛型约束（bounds）

```c
接口 可加 { 加 }
构 数 { 整 v; }
整 数加(构 数 *a) { 返 a->v; }
实现 可加 于 数 { 加 = 数加 }

泛型 双倍: 可加(x) = (((调用 可加 加(&x)) + (调用 可加 加(&x))));   /* ⚠️ 这是旧宏语法形态 */
```

**实测输出**：`#45 泛型约束 PASS`

**⚠️ 注意本节的书写形态**：`泛型 双倍: 可加(x) = 体` 用的是**旧宏语法**（文本替换）。体里 `x` 出现两次 ⟹ **传 `变++` 类的实参会被求值两次**（见本章开头的实测对比）。
若要避免，把约束体写成只引用一次，或改用 `泛型函数` + `实例` 形态（但后者目前不支持 `: 接口` 约束语法）。

语法是 `泛型 名: 接口(参数) = 体`，参数类型**必须实现该接口**。

**官方用例**：`feat_zh_generic_bounds45.c`

### 1.3 字面量保护

```c
泛型函数 说(T) = 函数 T 说(T x) { 格式化 "T=%d\n", x; 返 x; }
实例 说(整);
```

**实测输出**：`LITSTR T=7`

体里 `"T=%d\n"` 的 `T` 是字符串内容，**逐字保留**；替换只作用于标识符 token。

**官方用例**：`feat_zh_generic_string_ok.c`

### 1.4 泛型指针分派

```c
泛型函数 取首(T) = 函数 T* 取首(T* p) { 返 p; }
实例 取首(整);

函数 整 主(空){
    整 x = 77;
    整* q = 取首[整](&x);
    格式化 "泛型指针=%d\n", *q;   /* → 77 */
    返 0;
}
```

**实测**：`泛型指针=77` ✅

类型形参可以出现在**指针位置**（`T*`），实例化后生成 `取首_整` 处理 `整*`。

## 二、借用 / 所有权 / 生命周期

### 2.1 存期（区域声明）与 outlives

```c
存期 a;              /* 声明生命周期域 */
存期 b: a;           /* b 活过 a（子域约束） */
整 x = 42;
借用 存期 a x;       /* 也可写 借用 a x; */
放还 x;
```

**错误码**：
- `A3005` —— 域未声明 / 重复声明 / 父域缺失
- `A3111` —— 存活约束违反（短借期赋给长借期）

**实测**：`存期 b: a;` 后先借 `b` 再借 `a` 合法；反过来报 `A3111`。

### 2.2 NLL（末次使用）

```c
整 x = 7;
整 *r = &x;
借用 x;
r = &x;
若 (*r > 10) 返 1;    /* r 末次使用 */
放还 x;
x = 9;                 /* 合法：借用已随末次使用结束 */
```

**实测输出**：`x=5`（`feat_zh_borrow_cfg.c`）

**注意**：**未写 `借用 x;` 的普通 `p = &x` 不在 NLL 检查范围**（保 C 兼容）。

### 2.3 借用检查覆盖矩阵（实测）

| 场景 | 结果 |
|:--|:--|

| `整 局=42; 整* r=&局; 返 r;` | ❌ **漏** |

## 三、类型系统

### 3.1 判別（sum type）与穷尽性

```c
判别 形 于 { 折(整 p), 数(整 n), 空无() };

函数 整 主(空){
    形 a;  a.tag = 形_数;  a.n = 42;
    整 r = 0;
    依据 r, a.tag 穷尽 形 对照 折(p): p, 数(n): n, 空无(): 0;
    格式化 "穷尽=%d\n", r;   /* 42 */
    返 0;
}
```

**漏分支** → `A6016 模式匹配非穷尽`

**注意**：`依据` 是**语句**，不是表达式；tag 常量命名是 `<判别名>_<变体名>`。

### 3.2 可空三态与错误联合

```c
可空 字* p = 找子串(句, "非");
解包 p;                       /* 未解包就取值 → A8001 */

错误 可空 整 求长(常 字 *串) {
    若 (串 == 0)     错 2;
    若 (串[0] == 0)  返 空;
    返 (整)strlen(串);
}
解构(v, t) = 求长(句);        /* 一次拿值 + tag */
```

### 3.3 细化类型（范围子集）

```c
细化 整(0, 100) 分数 = 150;   /* 初值越界 → 打印「细化 越界」并 exit(1) */
```

**限制**：只检查**声明初值**。后续赋值 `分数 = 150;` **不检查**（台账 D321）。

### 3.4 定长（依赖类型）

```c
定长 整 甲, 5;
甲[0] = 10; 甲[4] = 50;
甲[5] = 99;      /* → A2001 编译期越界: 数组 '甲'[5] 越界 (大小 5) */
```

**编译期越界拦截**，长度参与类型。

### 3.5 范围（Ada 风格运行时检查）

```c

范围 x 于 1 到 10;    /* → 打印「范围越界」并 exit(1) */
```

### 3.6 密封 / 抽象 / 实现

```c
接口 形状 { 整 面积(空); };
密封 形状;                     /* 之后 实现 形状 于 X → A6020 */
整 方_面积(空){ 返 42; }
构 方 { 整 边; };
实现 形状 于 方 { 面积 = 方_面积; };   /* ← 是赋值形式，不是函数体 */
```

```c
抽象 构 基 { 整 v; };         /* 不可实例化（值声明 → A6091），指针与继承不受限 */
构 具体 : 基 { 整 w; };
```

**抽象实测**（`feat_zh_abstract199_ok` 与自写探针一致）：

```c
抽象 构 基 { 整 v; };
构 具体 : 基 { 整 w; };
函数 整 主(空){
    具体 a; a.v = 3; a.w = 4;   /* 具体类型可实例化 */
    基 *p;                      /* 抽象类型指针可声明 */
    格式化 "ABSTRACT199 %d %d\n", a.v, a.w;   /* → ABSTRACT199 3 4 */
    返 0;
}
```

**实测**：`ABSTRACT199 3 4` ✅

**三条合法面同时成立**：① 抽象类型可定义 ② 具体类型继承合法（`构 具体 : 基`）③ 抽象类型指针可声明。**只有「直接实例化抽象类型」被拒（A6091）** —— 与 C++ 同款语义。

### 4.3 同步原语（全部实测可用）

| 特性 | 语法 |
|:--|:--|
| 互斥锁 | `互斥锁 m;` + `锁住 m { ... }`（真原子 CAS 自旋） |

| 原子 | `原子 加(&x, 5);` / `原子 读(&x)` |

### 4.4 Send/Sync

```c
线程安全 数据;      /* 标记类型可跨线程传递 */
线程不安全 数据;    /* 标记不可 */
```

### 4.5 协程（语法糖 + 用户运行时）

```c
协程(c, 函, ctx)   →   coro_init(&c, 函, ctx)
生成(g, 0, 5)      →   gen_init(&g, 0, 5)
异步 泵(ts,3,1,10) →   async_pump(ts, 3, 1, 10)
超时 N;            →   timer_deadline(N)
让出();            →   __coro_yield()
```

**重要**：这些**都需要用户自己定义回退函数**（`coro_init` / `gen_init` / `async_pump` / `timer_deadline`）。编译器只做脱糖，不背运行时。

**`让出()` 实测是真挂起** —— 打印「让出前」后不执行后续。

### 4.6 递归保护

```c
整 递(整 n){

    若 (n <= 0) 返 0;
    返 递(n - 1) + 1;
}
```

**实测**：`递归保护 2` + 递归 10 层 → `开始 | 递归过深`（正确终止）

### 4.7 重试

```c
整 尝试(空){ 返 0; }        /* 回退函数由用户定义：返回 0 = 成功 */

函数 整 主(空){
    重试 尝试(), 3;          /* 最多重试 3 次，成功即停 */
    格式化 "重试完成\n");
    返 0;
}
```

**实测**：`重试完成` ✅

**⚠️ `串数据` 不是给构建器用的** —— 源码 L11137：`串数据(s) → __qcc_nstr_data(s) (= s + 4)`，是给「原生串」类型用的。给构建器用会报 `A1001 未声明标识符`。

### 7.1 动态数组（Vec）完整用法

```c
动态数组 v;
追加 v, 10;              /* ← 是「追加」，不是「压入」 */
追加 v, 20;
整 n = 长度 v;           /* ← 无括号！带括号会当函数调用，报 A9001 参数为空 */
整 a = 取元素 v, 0;      /* ← 同样无括号 */
```

**实测**：`长度=2` / `取元素=10 20` ✅

**⚠️ 三个坑**：
1. 追加用 **`追加`**，不是 `压入`
2. **`长度`/`取元素` 必须无括号** —— 它们是**表达式层**内建（源码 L11027），写成 `长度(v)` 会被当函数调用
3. 声明生成的是内部 ID（`__vec_v_id`），`v` 本身不是普通变量

### 7.2 字符串构建完整用法

见 §6.2。要点：`追加串`/`追加字符`/`构建长度`/`释放串`，**全部无括号**。

## 八、错误处理

### 8.1 异常链（`试` / `捕获` / `抛出` / `若错`）

```c
整 r = 0;
试 {
    r = 1;
    抛出 5;
    r = 2;
} 捕获 {
    r = 3;
}
/* 实测 r = 3 —— 真跳转，r=1 和 r=2 都没生效 */
```

**关键**：`抛出` 只置 `ex_pending`（`qcc_rt.c` L1525），**跳转靠 `试` 块**。裸 `捕获 { 抛出 42; }` 什么都不会拦。

**官方三用例全过**：
- `feat_zh_throw_ok.c` → `THR 5 0 9`
- `feat_zh_excguard160_ok.c` → `EXCGUARD160 PASS`（**含守卫析构在异常路径正确执行**）
- `feat_zh_exchain_ok.c` → `EXC 3 9`

### 8.2 数据流单赋值

```c
数据流 整 甲 = 10;
甲 = 2;          /* → A6090 数据流: 变量 甲 是单赋值 */
```

### 8.3 恐慌 / 不安全

```c
恐慌 "出事了";       /* 打印后 exit(1) */

不安全 { ... }        /* 块内可调用被标记的不安全函数 */
不安全 危险;          /* 标记函数，调用必须在 不安全 {} 内 → 否则 A6088 */
```

### 8.4 溢出检查

```c
溢出检查 开;    /* 编译单元级开关：有符号 + - * 全部带运行时溢出检查 */
溢出检查 关;
```

**实测**：开 → 溢出点终止；关 → `-2147483648` 回绕。
