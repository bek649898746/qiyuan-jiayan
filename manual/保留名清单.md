## 四、撞了怎么办（换名对照）

| 想用的名字 | 撞了谁 | 换一个 |
|:--|:--|:--|
| `长` | `long` 类型词 | `规模` / `数量` / `上限` |
| `无` | `unsigned` 类型词 | `未找` / `缺失` / `空值` |
| `类` | `struct` 别名 | `类别` / `种类` |
| `栈` | 栈内建 | `存放` / `堆叠` |
| `最小` / `最大` | 内建函数 | `较小` / `较大` |
| `查找` / `过滤` / `映射` | 内建函数 | `找位置` / `筛选` / `逐项变` |
| `输出` / `格式化` | 内建 I/O | `打印` / `排版`（或直接用内建） |

> 💡 **通用规律**：甲言的**内建函数名**（`查找` `过滤` `映射` `最小` `最大` …）与**类型词**（`整` `长` `短` `单` `双` `无` `空` `构` `联` `枚` `常` `静` …）占用了大量常用中文词。
> **优先用"双字组合"拟名**（`规模` / `计数框` / `库存量`），撞词概率远低于单字。
