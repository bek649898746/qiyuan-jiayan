## 序言：为什么是母语

编程不是英文的专利。0 和 1 不说话，但**甲言**替它们说了中文。

甲言是一门以中文为关键字的编程语言。它的语法和 C 语言一模一样，只是把 `if` 换成「若」、`for` 换成「遍」、`int` 换成「整」……中文本身，就是这门语言的语法。

最了不起的是：**甲言是自己编译自己的**。它不需要别人喂，它用自己的中文源码，生成了和它完全一样的自己。这就是"自举"——一个生命能自己出生。

本教程带你从零开始，用自己的母语，学会编程。

## 第一章：第一个甲言程序

创建一个文件 `hello.jy`，写下：

```c
#include <stdio.h>

整 主() {
    输出("甲言，你好！\n");
    返 0;
}
```

逐行理解：
- `#include <stdio.h>` —— 引入输入输出工具（暂时记住即可）
- `整 主() { … }` —— 程序的入口，就像"故事从这里开始"
- `输出("甲言，你好！\n");` —— 把这句话打印到屏幕
- `返 0;` —— 告诉系统"我顺利完成了"

编译运行：

```bash
qcc_x86.exe hello.jy -o hello.exe
./hello.exe
```

屏幕出现：`甲言，你好！`

**你学会了第一个甲言程序。** 全程没有一个英文字母的命令词。

## 第二章：数据 —— 整、字、双

编程是"给数据取名字，然后让程序操作它们"。

| 中文 | 英文对应 | 是什么 |
|:--|:--|:--|
| `整` | int | 整数：1、-5、2026 |
| `字` | char | 字符：'甲'、'A' |
| `双` | double | 小数：3.14、2.718 |

```c
整 主() {
    整 年龄 = 16;
    双 圆周率 = 3.14;
    字 首字母 = 'A';   /* 单个字符用 ASCII；中文用字符串 */

    输出("年龄=%d, 圆周率=%.2f, 首字母=%c\n", 年龄, 圆周率, 首字母);
    返 0;
}
```

运行输出：`年龄=16, 圆周率=3.14, 首字母=A`

> 小提示：当前甲言支持英文单字符（`'A'`）；中文要用字符串（如 `"甲"`）+ `字拷` 处理。

**给数据起个中文名字，程序自己就会说话。**

## 第三章：判断 —— 若 / 否

让程序"思考"：

```c
整 主() {
    整 分 = 85;

    若 (分 >= 60) {
        输出("及格了！\n");
    } 否 {
        输出("继续努力。\n");
    }
    返 0;
}
```

- `若 (条件) { … }` —— 如果条件成立
- `否 { … }` —— 否则

输出：`及格了！`

## 第四章：循环 —— 遍 / 循环

让程序"重复做事"：

```c
整 主() {
    /* 用 遍 数 5 次 */
    遍 (整 i = 1; i <= 5; i++) {
        输出("第 %d 遍\n", i);
    }
    返 0;
}
```

输出：
```
第 1 遍
第 2 遍
第 3 遍
第 4 遍
第 5 遍
```

`遍` 是最常用的循环——"从 1 到 5，每遍做一次"。

## 第五章：函数 —— 给逻辑起个名字

把一段逻辑装进一个"盒子"，给它名字，随时调用：

```c
整 平方(整 x) {
    返 x * x;
}

整 主() {
    整 结果 = 平方(9);
    输出("9 的平方是 %d\n", 结果);
    返 0;
}
```

输出：`9 的平方是 81`

- `整 平方(整 x)` —— 定义一个函数：输入一个整数，返回它的平方
- `返 x * x;` —— 返回计算结果
- 函数是编程的积木。大程序 = 很多小积木。

## 第六章：字符串 —— 字拷

处理文字：

```c
#include <string.h>

整 主() {
    字 名字[32];
    字拷(名字, "启元");
    输出("你好，%s！\n", 名字);
    返 0;
}
```

输出：`你好，启元！`

- `字 名字[32]` —— 一个能装 32 个字符的盒子
- `字拷(名字, "启元")` —— 把"启元"复制进去
- `%s` —— 打印字符串的占位符

## 第七章：让甲言编译甲言（自举）

甲言最骄傲的能力：**它编译自己**。

```bash
qcc_x86.exe srclib_jiayan/qcc_work.jy -o v1.exe   # 甲言编译自己
./v1.exe srclib_jiayan/qcc_work.jy -o v2.exe      # 生成的结果再编译自己
./v2.exe srclib_jiayan/qcc_work.jy -o v3.exe
```

然后比较三个文件：

```bash
sha256sum v1.exe v2.exe v3.exe
```

你会发现：**三个文件的哈希完全相同**（`dc34276fa5e20fc4`）。

这意味着：甲言用自己生成了自己，而且每次生成都一样——**确定性**。这就是"自举"，是一个编译器"出生"的证明。

任何拿到甲言源码的人，都可以亲手重现这个奇迹。
