### 1.2 语法规则

1. **与 C 同构**：除关键字外，运算符、表达式、语句结构、预处理指令（`#include`/`#define`）与 C 完全一致。
2. **注释**：`/* */` 与 `//`，中文注释推荐。
3. **编码**：UTF-8。中文关键字与字符串字面量均 UTF-8。
4. **程序入口**：`整 主() { … 返 0; }`（等价于 `int main()`）。
5. **标识符**：可用中英文；推荐英文标识符 + 中文注释，或全中文。

### 1.3 最小完整程序

```c
#include <stdio.h>

整 主() {
    输出("甲言，你好！\n");
    返 0;
}
```

编译：`qcc_x86.exe hello.jy -o hello.exe`

### 1.4 已知编译器边界（训练时规避）

以下构造当前编译器支持有限（详见施工日志）：
- `struct` 标量 / 嵌套 struct 数组成员 / struct 指针成员
- `typedef enum` 使用
- `const char *` 数组
- 浮点字段运算（double/float 数组与复杂运算）
- 中文字符字面量（`'甲'`；中文请用字符串 `"甲"`）
- 二维数组初始化器、无大小数组初始化器（`int a[] = {…}`）
- `sizeof(数组名)`

建议：训练语料优先使用**纯 C 整数引擎**（见 `jiayan_engines/`）。

## 二、AI 训练数据集规范

### 2.1 数据格式

| 字段 | 说明 |
|:--|:--|
| `source` | 甲言源码（`.jy`），UTF-8 |
| `semantics` | 语义等价描述（中文） |

| `license` | Apache-2.0 |

### 2.2 数据来源

- `srclib_jiayan/qcc_work.jy` —— 自举核心（编译器源码，最高价值语料）
- `jiayan_engines/*.jy` —— 甲言化引擎（纯 C 整数翻译）
- `seed/qcc.jy` —— 种子编译器
- 用户贡献（Apache-2.0 授权）

### 2.3 质量要求

1. **可验证**：每条语料必须能被 `qcc_x86.exe` 编译。
2. **语义标注**：中文描述功能与算法，便于模型理解意图。
3. **边界标注**：涉及 1.4 节边界构造的，标注"受限"。

### 2.4 训练建议

- 先学关键字映射（37 个），再学自举源码（结构最丰富）。
- 以"母语到机器码"为任务目标：中文描述 → 甲言代码。
- 以 `jiayan_engines/` 为监督微调语料（正确性可编译验证）。
