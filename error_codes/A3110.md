# A3110 Copy+Drop 冲突

> 错误码 | 所有权 (A31xx) | 生成 2026-09-07

## 触发场景

对 析构 类型 或 含析构字段的容器 标注 复制（Copy），语义矛盾。

## 语法（甲言）

```c
析构 T, 析构T;
复制 T;    /* Copy+Drop 冲突 → A3110 */
```

## 修复建议

Copy 和 Drop 不能共存：要么去掉 析构，要么去掉 复制（改用显式 移入/克隆）。

## 示例

```c
/* 错 */ 析构 T, 析构T; 复制 T;
/* 对 */ 析构 T, 析构T;  /* 非 Copy，移动语义 */
```

## 说明

Copy 与 Drop 双向闭环拦截：析构类型标 Copy、含析构字段类型标 Copy 均报 A3110。
