# A9001 错误必须检查

> 错误码 | 错误联合 (A9xxx) | 生成 2026-09-07

## 触发场景

错误函数的返回值未被检查（未用 尝试 传播/判断，直接丢弃或传参/返回）。

## 语法（甲言）

```c
错误 整 f();
f();    /* 丢弃未检查 → A9001 */
```

## 修复建议

用 尝试 f(); 传播（有错即返回），或显式判断后使用。

## 示例

```c
/* 错 */ f();
/* 对 */ 尝试 f();
```

## 说明

错误联合 = 判别 结果（值/错）。未检查使用 = 类型错（对标 Rust Result 的 must_use）。
