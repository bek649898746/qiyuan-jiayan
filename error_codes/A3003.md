# A3003 可变借用再借

> 错误码 | 借用/所有权 (A3xxx) | 生成 2026-08-28

## 触发场景

变量已有可变借用(独占)时，再声明借用（只读或可变）

## 语法（甲言）

```c
可变借用 x; 借用 x;    /* 已有可变借用 → A3003 */
```

## 修复建议

放还可变借用后再借用

## 示例

```c
/* 错 */ 可变借用 a; 借用 a;
/* 对 */ 可变借用 a; 放还 a; 借用 a;
```

## 说明

可变借用独占期间不能有任何其他借用。与 v3.0 #3 对应。
