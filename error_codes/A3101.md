# A3101 移动后读取

> 错误码 | 借用/所有权 (A3xxx) | 生成 2026-08-28

## 触发场景

移入后源变量失效仍读取（源值已转移）

## 语法（甲言）

```c
移入 y, x; int r = x + 1;    /* x 已移动 → A3101 */
```

## 修复建议

用目标变量 y，或重新赋值 x 后再读取（重绑定恢复）

## 示例

```c
/* 错 */ 移入 b, a; int r = a;
/* 对 */ 移入 b, a; int r = b;
```

## 说明

移动语义完整：move 后源彻底失效，读取即拦截；重新赋值恢复可用。与 v3.0 #5 对应。
