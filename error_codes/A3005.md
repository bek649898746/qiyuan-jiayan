# A3005 生命周期域未绑定

> 错误码 | 借用/所有权 (A3xxx) | 生成 2026-09-07

## 触发场景

借用变量/引用时，所绑定的 存期 域未声明或无效。

## 语法（甲言）

```c
借用 a x;    /* 存期 a 未声明 → A3005 */
```

## 修复建议

先 存期 名; 声明域，再 借用 存期 名 x; 绑定。

## 示例

```c
/* 错 */ 借用 a x;
/* 对 */ 存期 a; 借用 a x;
```

## 说明

生命周期显式域：借用须绑定到已声明的 存期 域（0=函数级）。
