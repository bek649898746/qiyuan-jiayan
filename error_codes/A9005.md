# A9005 接口不匹配

> 错误码 | 接口 (A9xxx) | 生成 2026-09-07

## 触发场景

字段/对象类型 与 接口引用形参/动态调用 的接口不匹配，或类型未实现接口。

## 语法（甲言）

```c
接口 画 { 画 }
f(接口 画 s);   /* 传 未实现 画 的类型 → A9005 */
```

## 修复建议

用 实现 画 于 类型 { ... } 实现接口，或传 &实现对象/接口引用变量。

## 说明

接口引用：类型须 实现 接口，字段传参/内联盒装 接口须匹配。
