# A5002 restrict 别名冲突

> 错误码 | restrict/契约 (A5xxx) | 补齐 2026-09-09

## 触发场景

基对象已被 restrict 指针占用时再次作为 restrict 指针指向（restrict 独占别名）

## 语法（甲言）

```c
restrict 整 *p = &x;    /* p 独占 x */
restrict 整 *q = &x;    /* x 已被 p 占用 → A5002 */
```

## 修复建议

同一基对象只允许一个活跃 restrict 指针；移除其一或改用普通指针

## 说明

restrict 承诺指针独占访问——多个 restrict 指向同对象违反正向别名规则（号合.0 #36）。
