# A4001 未初始化读取

> 错误码 | 明确初始化 (A4xxx) | 生成 2026-08-28

## 触发场景

声明未初始化就读取（直接读/作实参/if条件/复合赋值隐含读/返回）

## 语法（甲言）

```c
int x; int r = x + 1;    /* x 未初始化 → A4001 */
int x; x += 3;    /* 复合赋值隐含读 → A4001 */
```

## 修复建议

声明时初始化：int x = 0; 或先赋值再读取：int x; x = 5;

## 示例

```c
/* 错 */ int x; int r = x;
/* 对 */ int x = 0; int r = x;
/* 对 */ int x; x = 5; int r = x;
```

C 头号隐蔽 bug：未初始化变量运行时随机值，AI 无运行时上下文可查 → 编译期拦截。与 v3.0 #78 对应。
