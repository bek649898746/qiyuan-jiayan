# A3004 借用期移动

> 错误码 | 借用/所有权 (A3xxx) | 生成 2026-08-28

## 触发场景

变量被借用(只读)时作为移入源（借用期所有权不可转移）

## 语法（甲言）

```c
借用 x; 移入 y, x;    /* 借用期 move → A3004 */
```

## 修复建议

先放还借用再移入

## 示例

```c
/* 错 */ 借用 a; 移入 b, a;
/* 对 */ 借用 a; 放还 a; 移入 b, a;
```

## 说明

借用期间不能转移所有权（Rust 借用规则）。与 v3.0 #10 对应。
