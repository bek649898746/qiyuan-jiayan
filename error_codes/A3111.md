# A3111 生命周期存活约束违反（重借用延长既有借期）

> 错误码 | 借用/生命周期 (A31xx) | 生成 2026-09-07

## 触发场景

对同一变量重借用（共享借叠加）时，新借用的存期比既有借期更长——短生命周期引用赋给长生命周期变量。既有存期必须活过（outlive）新存期。

## 语法（甲言）
10→
```c
存期 a;
存期 b: a;      /* b 活过 a */
借用 x 存期 a;  /* 短借期 a */
借用 x 存期 b;  /* 延长至 b：a 不活过 b → A3111 */
```

## 修复建议

- 先 `放还 x;` 再重新借用更长的存期；
- 或声明更长既有借期 `存期 b: a;` 并先借 b 再借 a；
- 或保持新借期 ⊆ 既有借期（先长后短）。

## 示例
20→
```c
/* 错 */ 借用 x 存期 a; 借用 x 存期 b;   /* a 不活过 b */
/* 对 */ 借用 x 存期 b; 借用 x 存期 a;   /* b 活过 a, a ⊆ b */
```

## 说明

存活约束（outlives）传递判定 `活过(甲域, 乙域)`：沿 `域约束` 链走，`甲域==乙域` 或链达 `乙域` 即成立。0=函数级借期活过一切显式域；函数级延长为非法（既有显式域不能延长至函数级）。
