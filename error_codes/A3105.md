# A3105 悬垂引用返回

> 错误码 | 所有权 (A31xx) | 生成 2026-09-07

## 触发场景

函数返回指向局部变量的引用（直接 return &x 或间接返回引用变量指向局部）。

## 语法（甲言）

```c
整 *f() { 整 x = 0; 返 &x; }   /* 返回局部地址 → A3105 */
```

## 修复建议

返回堆分配、静态变量或调用者传入的引用；局部变量不可逃逸其作用域。

## 示例

```c
/* 错 */ 整 *f() { 整 x; 返 &x; }
/* 对 */ 整 *f() { 返 新分配(...); }
```

## 说明

悬垂引用检测：直接 + 间接（返回引用变量指向局部）。返回静态/堆引用放行。
