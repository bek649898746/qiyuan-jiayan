# A3106 守卫变量不可部分移动 / 字段外流

> 错误码 | 所有权 (A31xx) | 生成 2026-09-07

## 触发场景

对守卫(析构)类型变量做部分移动（移出字段/元素），或把非 Copy 字段拷贝外流（会双所有权）。

## 语法（甲言）

```c
构 S { 线性 T t; } 守卫 s, 析构S;
移入 目标, s.t;    /* 部分移出守卫变量 → A3106 */
```

## 修复建议

整对象析构会作用到已移出字段——先移出整个变量/丢弃，或复制整个对象。

## 示例

```c
/* 错 */ 移入 目标, s.t;
/* 对 */ 移入 目标, s;  /* 整个移出 */
```

## 说明

Rust E0509 对应。守卫变量整对象析构，部分移动会破坏析构完整性。
