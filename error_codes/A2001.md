# A2001 越界 / 除零 / 类型错配

> 错误码 | 语义 (A2xxx) | 生成 2026-09-07

## 触发场景

数组越界、除零、类型错配（整数赋指针等）等语义错误。

## 语法（甲言）

```c
整 a[3]; a[5] = 0;    /* 越界 → A2001 */
整 *p = 1851;         /* 整数赋指针 → A2001 */
```

## 修复建议

检查索引范围 / 除数非零 / 指针只能赋地址或 空(0)。

## 说明

语义检查：常量级越界/除零/类型错配（探雷雷2 等）。
