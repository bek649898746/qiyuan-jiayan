# A3001 借用期写/读

> 错误码 | 借用/所有权 (A3xxx) | 生成 2026-08-28

## 触发场景

变量被借用(只读)时写，或被可变借用(独占)时读取

## 语法（甲言）

```c
借用 x; x = 5;    /* 只读借用期写 → A3001 */
可变借用 x; int r = x;  /* 可变借用期读 → A3001 */
```

## 修复建议

先放还借用再操作：放还 x; 之后再写/读

## 示例

```c
/* 错 */ 借用 a; a = 5;
/* 对 */ 借用 a; 放还 a; a = 5;
```

## 说明

借用检查器：只读借用(多读单写)禁止写；可变借用(独占)冻结读和写。与 v3.0 #2/#3 对应。
