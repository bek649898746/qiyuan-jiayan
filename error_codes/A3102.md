# A3102 重复移动

> 错误码 | 借用/所有权 (A3xxx) | 生成 2026-08-28

## 触发场景

已移动(未重新赋值)的源再次作为移入源

## 语法（甲言）

```c
移入 b, a; 移入 c, a;    /* a 已移动 → A3102 */
```

## 修复建议

重新赋值 a 后再移入

## 示例

```c
/* 错 */ 移入 b, a; 移入 c, a;
/* 对 */ 移入 b, a; a = 5; 移入 c, a;
```

## 说明

所有权一次只能转移一次；重赋值恢复后可再次移动。与 v3.0 #1/#5 对应。
