# A9002 无隐式转换

> 错误码 | 类型根治 (A9xxx) | 生成 2026-09-07

## 触发场景

双精度值隐式赋给整型变量（narrowing 无隐式转型）。

## 语法（甲言）

```c
整 x = 3.14;    /* 双精度 → 整 无隐式 → A9002 */
```

## 修复建议

用 转 整数(...) 显式转换。

## 示例

```c
/* 错 */ 整 x = 3.14;
/* 对 */ 整 x = 转 整数(3.14);
```

## 说明

无隐式转换：双精度→整数 narrowing 须显式 转。C 兼容零变化（纯英文 C 不触发）。
