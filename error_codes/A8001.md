# A8001 可空必须解包

> 错误码 | 可空类型 (A8xxx) | 生成 2026-09-07

## 触发场景

可空类型变量未解包就解引用（星/箭头/下标）。

## 语法（甲言）

```c
可空 整 *p = 无;
*p = 5;    /* 未解包 → A8001 */
```

## 修复建议

先 解包 p; 判空，或 判空 p == 无 后处理。

## 示例

```c
/* 错 */ *p = 5;
/* 对 */ 解包 p; *p = 5;
```

## 说明

可空 T = 判别 可空值（有值/无值）。未解包解引用是类型错。
