# A3002 可变借用冲突

> 错误码 | 借用/所有权 (A3xxx) | 生成 2026-08-28

## 触发场景

变量已有借用(只读或可变)时，再声明可变借用（独占互斥）

## 语法（甲言）

```c
借用 x; 可变借用 x;    /* 已有只读借用 → A3002 */
```

## 修复建议

放还现有借用后再可变借用

## 示例

```c
/* 错 */ 借用 a; 可变借用 a;
/* 对 */ 借用 a; 放还 a; 可变借用 a;
```

## 说明

可变借用是独占的（Rust 式 &mut）：已有任何借用时不能再可变借用。与 v3.0 #3 对应。
