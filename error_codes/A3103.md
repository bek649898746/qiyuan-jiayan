# A3103 移动后借用

> 错误码 | 借用/所有权 (A3xxx) | 生成 2026-08-28

## 触发场景

已移动(未重新赋值)的变量被借用（所有权已转移，无可借）

## 语法（甲言）

```c
移入 y, x; 借用 x;    /* x 已移动 → A3103 */
```

## 修复建议

重新赋值 x 后再借用

## 示例

```c
/* 错 */ 移入 b, a; 借用 a;
/* 对 */ 移入 b, a; a = 5; 借用 a;
```

## 说明

移动后源失效不能借用。与 v3.0 #10 对应。
