```powershell
powershell -ExecutionPolicy Bypass -File scripts/verify_multilang.ps1
```

## 三、⚠️ 归档时的最小修复（3 个文件，各 3 行）

打捞到的源码是 **2026-10-11** 的产物。此后编译器加严了「**前向读**」检查（`A1001`：全局名字在声明之前被写），于是其中 3 个文件被拦住：

| 文件 | 现象 | 修法 |
|:--|:--|:--|
| `go/go1.c` | `[ERR] A1001 全局 '栈顶' 在其声明之前被写` | 把 3 行 VM 声明（`操作栈`/`栈顶`/`值区`）从 `编源()` 之后移到其**前向声明之前** |
| `rust/rs1.c` | 同上 | 同上 |
| `cpp/cpp1.c` | 同上（该文件用 `static int` 英文写法） | 同上 |

**这不是掩盖问题，反而是一个活证据**：它证明新加的前向读检查**真的会拦住真代码**，而不是空转。
修复只动声明位置，**零逻辑改动**；修复前后对比见下表：

| 文件 | 修复前 | 修复后 |
|:--|:--|:--|
| `go/go1.c` | rc=1（A1001 拦下） | rc=0，正常运行 |
| `rust/rs1.c` | rc=1（同上） | rc=0，正常运行 |
| `cpp/cpp1.c` | rc=1（同上） | rc=0，正常运行 |

## 四、诚实标注（这些是什么、不是什么）

| 是 | 不是 |
|:--|:--|
| 用甲言写的、能编译能运行的**语言实现原型** | 不是完整的、可用于生产的语言实现 |
| 9 条线各自压一个**招牌机制**（缩进感知/字节码/不可变绑定/静态类型检查…） | 不是「九个语言的完整支持」 |
| **9/9 入口文件实测可编可跑**（本机 2026-10-20） | 不是「329 个用例全部复跑通过」——那 329 例的验收记录属内部审计档案，本目录只提供**源码本体** |

**已知限制**（与 `manual/多语言实现.md` 一致）：

1. 本机**没有** JDK / Go / Rust / TypeScript / C++ / C# 任何官方工具链，因此**无官方实现交叉对照**；正确性靠「逐字节手验字节码 + 自建 VM 执行」，**不等于与官方行为一致**。
2. C# 线（`csharp/`）改了 C++ 线的内核语义（值语义 → 引用绑定），两线**内核不同源**，此项**未结项**。
3. JS / JVM 两线的「329/326」计数无独立报告支撑（原始记录为转述），本目录不重复该数字。
