# 甲言 × C 混合编程最小示例

甲言写应用框架，C 写性能热点，两边用普通 `.o` 链接。本示例输出 `hot_mulrow=240`
（1×2 + 2×3 + … + 8×9）。

## 四步

```powershell
# ① C 编热点
gcc -O2 -c hot.c -o hot.o

# ② 甲言编框架（-c 必须显式带 -o，否则默认产出 a.exe）
..\..\qcc_zh_seed.exe -c app.jy -o app.o

# ③ 链接（甲言 .o + C .o）
..\..\jyld.exe app.o hot.o -o app.exe

# ④ 运行
.\app.exe
# 期望：hot_mulrow=240
```

也可直接跑 `.\build.ps1`（内部就是这四步）。

## 三个必须知道的点

1. **`qcc -c` 必须带 `-o`**。`-c` 只表示「产出目标文件」，不指定 `-o` 时仍走默认输出名。
2. **外部符号未定义会响亮失败**。只声明 `hot_mulrow` 却不链接 `hot.o` 时，编译 EXE
   会报 `A6100 未定义的外部符号`，不再静默返回 0。分模块编译（`-c` / `-S`）仍允许
   未解析符号，等链接器处理。
3. **热点放 C，业务放甲言**。矩阵乘这类循环密集代码用 `gcc -O2`；框架、错误处理、
   并发调度用甲言。

## 文件

| 文件 | 作用 |
|:--|:--|
| `app.jy` | 甲言主逻辑，声明并调用外部 C 函数 |
| `hot.c` | C 热点实现 |
| `build.ps1` | 一键执行上面四步 |
